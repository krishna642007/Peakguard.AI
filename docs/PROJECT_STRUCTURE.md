# Project Structure & Requirement Coverage

## Repository layout

```text
peakguard-capacity-simulator/
├── app.py                      # Streamlit dashboard (MVP UI, rollback demo)
├── simulator.py                # Engine + Legacy/PeakGuard policies + scenarios
├── generate_data.py            # Synthetic 30-day historical load generator
├── run_experiments.py          # Full scenario x policy experiment runner
├── sensitivity.py              # One-at-a-time sensitivity sweeps
├── test_simulator.py           # 6 pytest tests (all passing)
├── requirements.txt            # streamlit, pandas, numpy, plotly, pytest
├── run_app.bat / run_all.bat   # Windows one-click helpers
├── README.md                   # Overview, quickstart, verified results
├── data/
│   └── historical_load.csv     # 43,200 rows, seeded (regenerate: generate_data.py)
├── outputs/                    # Pre-generated, regenerated by runners
│   ├── experiment_results.csv
│   ├── sensitivity_results.csv
│   └── trace_<scenario>_<policy>.csv
└── docs/
    ├── stakeholder_assumptions.md
    ├── architecture.md
    ├── data_schema.md
    ├── experiment_results.md
    ├── risk_register.md
    ├── user_guide.md
    └── stakeholder_validation.md
```

## Brief requirement -> where it is satisfied

| Requirement | Evidence |
|---|---|
| Baseline | Legacy average-utilisation policy (`legacy_policy`), tested in `test_simulator.py` |
| End-to-end working prototype | `app.py` dashboard + `simulator.py` engine, one-command run |
| At least 3 edge/failure cases | scheduled_sale, sudden_spike, worker_loss + fleet-cap exhaustion in sensitivity |
| Measurable experiment (historical load, seasonal events, queue depth, latency, scaling actions) | `data/historical_load.csv` + `run_experiments.py` -> `outputs/experiment_results.csv` |
| Short user/stakeholder validation | `docs/stakeholder_validation.md` (5 evaluators, task script, survey results) |
| Not just a notebook | Web dashboard, CLI runners, tests, exports |
| Stakeholder assumptions | `docs/stakeholder_assumptions.md` |
| Architecture diagram | `docs/architecture.md` (Mermaid) |
| Data schema | `docs/data_schema.md` |
| Functioning MVP | Dashboard + engine; `pytest -q` green |
| Before-and-after comparison | Legacy vs PeakGuard tables in `docs/experiment_results.md` |
| Risk register | `docs/risk_register.md` |
| User guide | `docs/user_guide.md` |
| Reproducible repository | Fixed seeds, pinned deps, pytest, deterministic generators |
| Runs on modest hardware / free tier | CPU-only, ~1 s per scenario, no external services |
| Service-level compliance quantified | Availability %, P95 latency, breach minutes vs 99.9% / 300 ms |
| Migration/coexistence + rollback demo | Shadow -> canary -> rollback panel with audit log in `app.py` |
| Sensitivity analysis with decision-changing assumptions | `sensitivity.py` + `docs/experiment_results.md` |
| Baseline / target / measured / error analysis | `docs/experiment_results.md` |
